# Logs

Un fichier par run automatique (ou manuel), nommé `YYYY-MM-DD-<boucle>.md`
(ex : `2026-08-22-collecte.md`). Chaque log contient : ce qui a été fait, les
sources consultées, ce qui a été retenu/écarté, et le coût (tokens/durée) quand
disponible. C'est la trace que relit la boucle de rétro hebdomadaire.
